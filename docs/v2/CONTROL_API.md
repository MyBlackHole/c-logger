# 刷新与重开：统一状态接口

本增量基于 #226 合并后的主线，替换开发版的实例/默认刷新和重开签名与错误风格，
不为旧 API 保留包装、别名或宏。创建、消费式销毁与默认槽借用已经迁移，不重复建设。

## 公开入口与所有权

```c
int logger_flush(logger_t *instance);
int logger_reopen(logger_t *instance);
int logger_default_flush(void);
int logger_default_reopen(void);
```

四个函数成功返回0，失败返回负错误码，所有正常返回都保留调用方进入时的errno。
它们只借用实例，不创建、解绑或销毁实例。显式实例的调用者负责保证对象存活；
默认入口在一个代次内取得读侧借用，返回前确认归还，不把操作转移到后继代次。

旧 `logger_flush_instance_status`、`logger_flush_instance`、`logger_flush_status`、
`logger_reopen_instance` 符号移除。`logger_flush`、`logger_reopen` 现在必须传实例，
无参旧调用不再合法。仍可显式 `(void)logger_flush(instance)` 丢弃结果，但库不另设
一个忽略错误的入口；这不是推荐的可靠性策略。

## 错误和副作用

进程准入先于读取实例字段：未初始化-ENODEV，初始化中-EAGAIN，子方未显式重建
-ECHILD；注册/重建失败返回该阶段保存的错误。同线程重入-EDEADLK。没有成功建立
取消保护时返回其错误，不进入后端。就绪后空实例-EINVAL；重开未选择文件输出的实例
仍为-EINVAL，不把此前语义暗中改为新值。停止实例-ESHUTDOWN。

默认槽为空-ENODEV、绑定转换期间-EAGAIN、延迟读者代次失效-ESHUTDOWN；失败不解绑。
新默认入口直接转发实例返回值，不能从已保留的errno再猜测错误。

显式刷新继续先捕获队列预留水位、等待包括已出队未完成批次的输出，再尝试文件同步。
仍保留之前的粘滞首错；重开成功不会清除它。首个业务错误优先于后续同步/取消恢复
错误；没有主错时取消策略恢复失败也必须返回。默认生命周期锁的解锁证明失败仍以
该安全错误为最终结果并毒化默认槽，不能用普通I/O错误掩盖未确认的借用归还。

负返回不表示没有发生I/O：例如文件已切换、同步已完成后，解锁或取消恢复才报告
错误。不得机械重试以求一次成功，更不能据此销毁仍被借用的实例。取消恢复之前
仍须完成锁释放；恢复后不得再解引用实例。作用域收尾不再丢弃恢复错误，但不会
把已经完成的工作伪装成可回滚事务。既有延迟取消或入口前禁用取消合同不变。

```c
int rc = logger_flush(owner);
if (rc) {
        /* 使用 -rc 判断原因；若接入 perror，先显式设置 errno = -rc。 */
        return rc;
}
```

输出完成不等于Syslog远端持久化；flush仍按原合同对文件执行同步，没有新增硬时限、
跨进程全序或物理掉电保证。文件同路径独占及fork子方旧指针失效规则不变。

## 验证范围

`xmake test -g control-api -j1`：四个公开场景（未初始化、同步、异步、真实重开失败），
以及22个独立错误场景。完整静态配置分别把错误场景链接生产归档和白盒支持归档，
共48注册项；共享配置公开场景链接真实DSO，白盒仍用静态支持归档，共26项。
静态链接包装不是DSO内部拦截证据。

错误场景覆盖取消建立/恢复、fsync与重开主错、主错加恢复错误、实例锁与默认读锁
获取/释放失败，并检查原errno保留。生产拒绝、既有完成水位/预留空洞、取消、
文件故障、默认代次/关闭准入回归直接迁移新接口。历史`flush-void`用例名称保留为
原测试身份，当前只调用同一新函数并选择忽略结果或记录测试回执，不再调用旧包装。

安装后的C11/C++11消费方实际调用四个签名；类型正反例拒绝旧无参签名、void函数
指针以及删除的四个符号，共新增八组对照。动态装载还检查旧符号不存在。
文档只定义测试合同，不表示某个源码提交已通过；执行结果须绑定真实源码树、
工具链、实际通过、失败和跳过，不挪用 #223/#226 的历史绿色。

记录接受状态、其余指标/级别/上下文与Console接口的错误风格仍是后续工作；
本增量不把整个API迁移或正式发布任务结项。
