# 2.0 生产验收边界

本页针对不含 Audit 的 ABI 2 正式发布产物。

## 发布身份与持续验证

- 根 VERSION=2.0.0，与 SONAME 2 / LOGGER_2.0 和安装/打包元数据一致；这是 ABI 2 版本身份。
- 2.0 公开 API/ABI 合同见[当前合同](../abi/LOGGER_2_0_CONTRACT.md)；正式发布源码与资产以 `v2.0.0` 标签和对应 GitHub Release 为准。后续发布仍须使用显式现存标签并完成验收。
- Audit/密码学模块源码和专用测试已退役；私有/回归支持库仍用于普通 Logger 故障与锁检测，不能进入安装产物。
- 每次生产候选须核对 GCC/Clang、共享/静态、ASan/UBSan、TSan、安装消费、制品隔离和声明的平台证据。相关源码与构建输入相同的历史平台证据可按[发布工程](RELEASE_ENGINEERING.md)记录等价承接，保留旧 SHA 并标明未重新执行；不能冒充最终提交或发布包的新运行。

## 运行与部署边界

- 平台限定 Linux x86_64/ELF64、内核 >=5.10、glibc >=2.31；GCC >=9、Clang >=10，公共头文件支持 C++11。musl、AArch64 和 32 位不在当前支持范围。
- 宿主拥有显式 Logger 实例。销毁/卸载前必须停止并 join 所有借用者；原始指针不支持并发销毁、跨静态库副本使用或销毁后重试。
- 文件目录必须可信，文件末级符号链接/硬链接被拒绝。锁只是协作协议，不抵抗不合作写入者、恶意目录/锁 inode 替换；不支持 NFS/SMB 等网络文件系统。
- 内部轮换要求 RENAME_NOREPLACE，不做覆盖式降级。错误可能发生在部分字节已写入后，业务重试可能重复；检查 flush/销毁状态与已锁存错误。
- Syslog 仅支持本地非阻塞 Unix 数据报；不提供磁盘重试队列、失败记录重放、远端持久确认或绝对 I/O 时限。重连仅由后续日志触发。
- Logger/Console 不是信号安全 API。有效资源快照的普通 libc fork 子进程可以在
  fork 返回后的常规上下文显式重建新域，但父进程实例指针不能继承复用；
  原始系统调用 fork、_Fork/vfork、注册窗口与无可信快照路径仍拒绝重建。
  不支持跨调用 longjmp/pthread_exit、宿主取消私有工作线程或回调等待环；
  多线程 fork 的宿主外部 libc 状态不受本库内部协调器保护。
- 支持延迟取消或入口前已禁用取消；ASYNC+ENABLE 不在一般 API 支持契约内。取消延期期间底层文件/stdio 和锁操作仍可能阻塞。
- Logger 的 stderr 与启动输出路径保护调用线程免受本次写入新产生 SIGPIPE 的默认终止，保留宿主处理器、信号屏蔽字和既有待处理信号。Console 的 stdio 路径也采用线程局部保护，关闭管道返回-EPIPE并保留入口errno；更早的格式错误保留首错。均不改变宿主全局信号处置。
- 普通日志不提供审计事务、哈希链、不可变存储或可信锚点。

## 持久性证据范围

基本 API 验收覆盖参数/返回值、并发、资源、轮转及正常 flush/关闭语义，保留进程
SIGKILL 与普通文件轮转切断点故障回归。既有 flush/fsync 契约不变。当前不维护
VM/断电测试，其专用程序、脚本及 CI 已移除；历史 Audit 或 VM 测试的成功
不替代当前普通 Logger 验证。进程证据不证明物理控制器/磁盘易失缓存、
RAID/HBA 或具体部署介质的断电安全；这类认证不属于基本 API 发布门槛。
最低内核/glibc 要有实际虚拟机/运行时证据，不能仅从 ELF 符号版本推导内核兼容性。

当前设计权威与支持细则见 [v2/README.md](v2/README.md)、[v2/SUPPORT_MATRIX.md](v2/SUPPORT_MATRIX.md)。
